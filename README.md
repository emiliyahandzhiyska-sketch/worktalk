# WorkTalk

Everyday English for work. A small ESL practice app for adult learners: 10 workplace phrases, flashcards with pronunciation (Web Speech API), a 5-question quiz, and progress saved in the browser.

Static site. No build step, no dependencies.

## Run locally

```
npx serve
```

Then open http://localhost:3000.

## Deploy

Works as-is on Vercel or Netlify. Point the platform at the repo root, no build command, output directory `.`
